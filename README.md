## Install

Requires [Rust](https://rustup.rs) **1.85+** and `~/.cargo/bin` on your `PATH`.

```bash
cargo install agent-usage
```

Verify:

```bash
agent-usage --help
```

<details>
<summary><strong>Build from source</strong> — for development or unreleased changes</summary>

```bash
git clone https://github.com/cesarferreira/agent-usage.git
cd agent-usage
cargo install --path . --locked
# or
make install-release
```

Debug install (faster compile, larger binary):

```bash
make install
```

Run without installing:

```bash
make build-release
./target/release/agent-usage
```

</details>

## Quickstart

```bash
agent-usage                    # one-shot bars for Claude, Codex, Cursor
agent-usage --watch            # refresh every 120s (or --watch 30)
agent-usage --refresh          # skip the cache
agent-usage --ttl 60           # cache lifetime in seconds (default 300, 0 = off)
agent-usage --only claude,cursor
agent-usage --format bars      # one compact line per provider
agent-usage --format json     # machine-readable (--json also works)
```

Results are cached for 5 minutes in `~/Library/Caches/agent-usage/cache.json`, and the last good data is shown if a refresh fails. macOS only. It reads local credentials and calls unofficial endpoints, so it can break without notice:

| Agent | Credentials | Source |
| --- | --- | --- |
| Claude | Keychain item `Claude Code-credentials` (`/usr/bin/security`) | `api.anthropic.com/api/oauth/usage` |
| Cursor | Session JWT in Cursor's `state.vscdb` (`/usr/bin/sqlite3`) | `cursor.com/api/usage-summary` (stale if Cursor.app hasn't run recently) |
| Codex | Managed by `codex app-server` | JSON-RPC `account/rateLimits/read` |

### Rex

Add to `~/.config/rex/init.lua` to open a live usage pane beside the focused one:

```lua
rex.action{
  name  = "agent_usage",
  title = "Agent usage",
  run   = function(ctx)
    rex.session.new_split{
      direction = "horizontal",
      ratio     = 0.7,
      layout    = rex.layout.block{
        flavor  = "com.superlogical.terminal.shell",
        options = { command = { "agent-usage", "--watch" }, exit = { on_completion = false } },
      },
    }
  end,
}
rex.bind("cmd+shift+u", "agent_usage")
```

## Development

Common tasks via the `Makefile`:

```bash
make              # check + build + test
make build        # debug build
make build-release
make install      # install debug binary
make install-release
make run ARGS="--json"
make check        # cargo check + clippy
make fmt          # format
make lint         # fmt check + clippy
make test
make clean
make demo         # install + show --help
```

Releasing (requires [cargo-release](https://github.com/crate-ci/cargo-release) and [git-cliff](https://github.com/orhun/git-cliff)):

```bash
make release                  # default minor bump
make release LEVEL=patch      # patch bump
make release LEVEL=major      # major bump
```

The pre-release hook regenerates `CHANGELOG.md` with `git-cliff` from your conventional-commit history (grouped into Features, Bug Fixes, etc. per `cliff.toml`) and commits it alongside the version bump. Pushing the resulting `v*` tag triggers the release workflow, which builds the multi-platform binaries and publishes a GitHub Release whose notes are generated by `git-cliff` from the same config.
